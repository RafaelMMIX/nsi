Ce notebook apparaîtra dans la section Cours des notebooks de tous les élèves, après vérification par Rafael.

  1. Relis ton notebook. Seules les cellules sont envoyées, pas les résultats affichés.
  2. Ouvre le formulaire (il faut un compte GitHub, gratuit). Le code du notebook est copié automatiquement : colle-le dans « Code du notebook » s'il n'est pas déjà rempli.
  3. Complète et envoie. Tu recevras une réponse sur GitHub quand le cours sera publié.
